# whamwong's blog

My personal blog, live at [whamwong.me](https://whamwong.me). Thanks for stopping by 🙏

Built with [Astro](https://astro.build). Posts are plain Markdown in `source/_posts/`, written in Obsidian. Images are hosted on Cloudflare R2 at `img.whamwong.me`. Pushing to `master` builds and publishes automatically.
